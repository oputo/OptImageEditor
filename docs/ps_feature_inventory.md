# PS 機能棚卸しシート（OptImageEditor MVP 選定用）

## 記入方法

「頻度」列に記号を入れてください。空欄のままの行は `×` として扱います。

| 記号 | 意味 |
|---|---|
| ◎ | ほぼ毎回の作業で使う |
| ○ | ときどき使う（週に数回程度） |
| △ | まれに使う。無くても PS に戻ればよい |
| × | 使わない |

- 「難度」は自作した場合の実装難度の目安（Claude の見積もりで、推測を含む）。低 / 中 / 高 / 極（PS 同等は非現実的）。
- 「メモ」には、こだわりの使い方やショートカットなど、自由に書いてください。
- 表に無い機能は、各カテゴリの末尾の空行に追記してください。

MVP は ◎ をすべて入れ、○ は難度が低〜中のものだけを入れる、という形で決める想定です。

## 12. 普段の作業の流れ（自由記述）

PS を開いてから納品するまでの典型的な流れを箇条書きで書いてください。MVP の優先順位を決めるときに一番参考になります。

- 素材の基本的編集（解像度やキャンバスサイズ変更、選択範囲を編集、素材全体の色調整）を施して保存や別名で保存。
- テキストや矢印を別レイヤーで記入。
- レイヤーやレイヤーセットの編集（追加、削除、リネーム、階層移動、Hide/Show、描画モード変更）、また調整レイヤー、スマートオブジェクトレイヤーの利用
- 素材の選択範囲をコピーし、新レイヤーにペーストしてレタッチ。

（利用頻度順。当方がゼロからペイントする訳ではなく、３Dアプリからのレンダリング出力や画像素材集、あるいはComfyUIからの出力を修正する作業が主になります）

## 13. PS で特にストレスを感じる点（自由記述）

- 起動が遅い / 重い
- ストレスを感じるまでではないが、AIとの連携においてサブスク/別料金のような仕組みから脱したい。つまりローカルAIとの密な連携を希望。
